# FindBack — AI-Powered Lost & Found

A MERN stack application that helps people report and recover lost items using
AI-assisted matching (Groq) on top of MongoDB candidate filtering and a basic
similarity score.

## Tech Stack

**Frontend:** React, Vite, React Router, Axios, Tailwind CSS
**Backend:** Node.js, Express, Mongoose, JWT, bcrypt, Helmet, CORS
**Database:** MongoDB
**AI:** Groq (free tier)
